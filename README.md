# Conditional Logic for Business Decisions
Python programs using if/elif/else to apply business rules.

| File | Description |
|------|-------------|
| `problem1_discount_eligibility.py` | Calculates a customer discount and final price based on membership and purchase amount. |
| `problem2_performance_bonus.py` | Calculates a bonus percentage and amount from salary and performance score. |
| `problem3_loan_risk.py` | Classifies a loan applicant as Low, Medium, or High Risk from credit score and income. |

## Assumptions
- Inputs are entered as plain numbers (no `$` or commas).
- Membership is entered as "yes" or "no" (not case-sensitive).
